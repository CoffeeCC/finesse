# Theme asset provenance and license

The Arcane Table assets added by this change are distributed under the repository MIT license (see LICENSE).

- Celestial table, phone background, transparent frame and card back: generated for this project with the built-in image-generation tool; exact prompts are in tools/theme/celestial-*-prompt.txt. The runtime versions are WebP encodings of the approved generated artwork. They contain no movie/show posters.
- Orb and movie/show deck boxes: original procedural Blender geometry and materials, authored for this theme. Editable .blend scenes and Python generators are included. Runtime GLBs and matching stills are derived from those sources.
- Quiet desk and collection folio artwork: generated with the built-in image-generation tool; exact prompts are in showcase-art-prompts.md. WebP runtime textures contain no library posters.
- Candle, holder, wax sprites and collection folio geometry: original procedural Blender sources in create-candle-folio.py and scenes/*.blend. GLBs and WebP stills derive from these sources. The packed showcase-light-study-v1.blend is a material/lighting study, not a browser UI recording; its textures are the original project assets above.
- Sun/moon coin: original Blender geometry/materials in create-celestial-coin.py and scenes/celestial-coin-v1.blend; self-contained GLB and two WebP stills. No borrowed game assets. Object sounds are original Web Audio synthesis in src/lib/sound.ts; there are no external recordings or audio downloads.
- Legacy base-style textures and card-back SVGs: original prototype art included only where the base stylesheet references it. No third-party fantasy game artwork or models are included.
- Story codex and draw deck: original procedural geometry/materials in create-action-props.py and their packed scenes. Matching GLBs/stills derive from those sources; leather normal grain is baked from original procedural noise. Their inlays reuse the original celestial card-back art. The action-props-light-study-v1.blend combines these original assets with the existing original candle/orb/coin/desk; it is a Blender study, not an application recording. Chain surface maps are derived in code from the original quiet-desk artwork; no third-party texture maps are used.
- Library artwork displayed by the app comes from the user's existing media server. That artwork is not bundled with this theme and is not relicensed by this file.
- Scribe desk: generated for this project using the built-in image-generation tool, with the exact prompt in scribe-desk-prompt.txt. The shipped WebP is an encoding of that original image; no user library artwork is baked into it.
- Articulated desk/case, hinges, key mechanism, lower lighting drawer, tuning fork and pull: original Blender geometry and reference camera/animation work in create-arcane-desk.py and packed scenes. Oxblood embroidered velvet albedo artwork was generated with the built-in image-generation tool; exact wide/portrait prompts are in velvet-lining-prompts.txt. WebP encodings are retained in the project and embedded in the desk GLBs. Native fallback layouts derive from these Blender cameras through desk_layout.py. Runtime baize color/normal/roughness and mobile contact maps are original procedural material work in arcaneBaize.ts. Hardware and tuning-fork sounds are original Web Audio synthesis, not recordings from a game or external library.
- Archive chest, desk key, fox mask, lyre, numbered obsidian die, gathering brazier, oracle prism, chronicle hourglass, artificer armillary, command wand and home waystone: original procedural Blender geometry/materials in create-navigation-trinkets.py with shared authoring helpers in blender_prop_tools.py. Editable .blend sources and matching GLB/WebP exports are included. These are a first asset pass; live animation/material polish is tracked separately from successful generation.
- Dispatch and stamp, linked rings, memory vessel and wax signet: original procedural Blender geometry/materials in create-correspondence-props.py and the matching editable scenes/*.blend files. GLBs and transparent WebP stills derive from those sources. The desk compartment currently uses CSS perspective and these existing original desk/signature textures; it is not a new Blender desk model or a physically simulated hinge.
- Three.js retains its own MIT license in the installed package. Existing Finesse font and dependency licenses remain unchanged.
